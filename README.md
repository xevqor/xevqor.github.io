## 🛡️ Core Architecture & Privacy Guarantee

**What you do here, stays here.**

XEVQOR is a suite of client-side cryptographic and privacy utilities designed with a strict **Zero-Knowledge Architecture**:
* **100% Client-Side Execution:** All encryption, hashing, token decoding, and key generation occur locally inside your browser using standard Web APIs.
* **Zero Tracking & Telemetry:** No analytics scripts, no cookies, no IP logging, and no third-party trackers.
* **Zero Data Collection:** No backend database or server ever receives, processes, or stores your inputs.
* **Offline Capable:** Once loaded, the utilities function completely without an internet connection.

## 🔍 How to Verify & Self-Host

Security relies on verification, not blind trust. You can independently audit or run XEVQOR locally on your own machine:

1. **Inspect Network Traffic:** Open your browser's Developer Tools (`F12` -> **Network** tab) while running any tool to verify zero outbound requests are made.
2. **Run Offline / Locally:**
   ```bash
   git clone https://github.com
   cd xevqor.github.io
   ```
   Open `index.html` directly in any modern web browser or serve it via a local static server.
