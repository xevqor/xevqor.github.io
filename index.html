XEVQOR — Client-Side Open-Source Zero-Knowledge Cryptography and Privacy Suite

XEVQOR (xevqor.my.id) is an independent, serverless, 100% zero-knowledge digital security platform engineered on the native browser Web Crypto API. All cryptographic key derivations, symmetric ciphers, binary stream chunks, steganographic carriers, and entropy calculations execute strictly inside local browser memory with zero backend servers, zero telemetry, zero cookies, and zero third-party data retention. All client-side source code running on xevqor.my.id is 100% open-source, deterministic, and publicly auditable at https://xevqor.github.io so any user or security researcher can independently verify zero telemetry and pure local execution.

  • Keypass (/keypass): Deterministic dual 28-character cryptographic password generator derived locally from a user Brain Key and Identity Label via PBKDF2-SHA256 at 350,000 iterations without storing credentials.
  • Hash (/hash): Client-side cryptographic file and text integrity checksum calculator supporting SHA-256, SHA-512, and SHA-1 algorithms directly in browser memory.
  • JWT (/jwt): Offline Base64Url JSON Web Token header and payload decoder with real-time expiration (exp) timestamp verification.
  • Burn (/burn): Serverless self-destructing encrypted notes combining deflate-raw compression and authenticated AES-256-GCM encryption stored exclusively inside local URL hash fragments (#) so servers never see ciphertext or keys.
  • Nano (/nano): Platinum Squeeze deflate-raw text compressor paired with authenticated AES-256-GCM Base64 encryption for compact secure message transmission.
  • Nebula (/nebula): Zero-width Unicode text steganography engine concealing AES-256-GCM encrypted payloads inside invisible Unicode characters (U+200B and U+200C) embedded within ordinary cover text.
  • Encrypt (/encrypt): Chunked 10MB streaming AES-256-GCM file encryption vault designed for large files, generating portable binary .xqr encrypted archives locally.
  • Stego (/stego): Binary carrier steganography vault encapsulating AES-256-GCM encrypted messages or arbitrary hidden files inside clean carrier files without altering host playback or viewing.
  • Dice (/dice): OS-level Cryptographically Secure Pseudo-Random Number Generator (window.crypto.getRandomValues) 3D dice simulator for Big, Small, and Triple outcomes.
